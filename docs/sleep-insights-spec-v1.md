# [기획서] 인사이트 중심 수면 대시보드 및 맞춤형 수면 추천 v1

이 기획서는 Android Health Uploader 앱을 단순한 데이터 백업 도구를 넘어, 사용자에게 개인화된 건강 통찰을 제공하는 '수면 분석 파트너'로 진화시키기 위한 명세서입니다.

---

## 1. Computations (가공 지표 목록)

데이터 소스(Supabase `health_daily`)로부터 다음과 같은 지표를 추출 및 계산합니다.

### 핵심 수면 지표
- **실제 수면 시간 (Total Sleep Time):** `sleep_duration_minutes` 값.
- **수면 효율 (Sleep Efficiency):** `(sleep_duration_minutes / (sleep_duration_minutes + sleep_awake_minutes)) * 100` (%)
- **수면 규칙성 점수 (Regularity Score):** 최근 7일간 '취침 시각'과 '기상 시각'의 표준편차(Standard Deviation)를 점수화. (100점 만점, 편차가 클수록 감점)
- **수면 단계 비율:** 전체 수면 시간 대비 Deep, REM, Light 수면의 백분율.

### 통계 및 추세 지표
- **7일/30일 이동 평균:** 수면 시간 및 규칙성 점수의 평균치.
- **수면 부채 (Sleep Debt):** 사용자 설정 목표 시간(기본 8시간)과 실제 수면 시간의 차이를 최근 7일간 누적한 값.
- **수면 윈도우 추세:** 취침 및 기상 시각이 지난주 대비 앞당겨졌는지, 늦춰졌는지에 대한 기울기 분석.

## 2. Recommendation Heuristic (v1)

고급 바이오메트릭(HRV 등)이 없어도 가용한 데이터를 통해 신뢰할 수 있는 추천 알고리즘을 제안합니다.

### 추천 목표 수면 시간
- **계산식:** 최근 30일 중 '활동량(steps, active_calories)'이 상위 25%인 날의 평균 수면 시간을 '최적 시간'으로 설정.
- **범위:** 최적 시간 ± 30분 (최소 6시간, 최대 9시간 제한).

### 추천 취침/기상 윈도우
- **취침 윈도우:** 최근 7일간 규칙성이 가장 높았던 날들의 평균 취침 시각 ± 20분.
- **기상 윈도우:** 추천 취침 시각 + 추천 목표 수면 시간.

### 데이터 신뢰도 (Confidence Level)
- **High:** 최근 21일 중 18일 이상의 데이터 존재 + 수면 단계(stages) 데이터 80% 이상 포함.
- **Mid:** 최근 7일 중 5일 이상의 데이터 존재.
- **Low:** 데이터가 3일 미만이거나 결측률이 높음 (이 경우 추천 대신 '데이터 수집 필요' 메시지 노출).

## 3. UI Spec (화면 구성)

### A. DashboardFragment (메인 화면)
- **상단: 오늘의 수면 요약 카드** (수면 시간, 효율, 전날 대비 증감)
- **중앙: AI 인사이트 카드** (Heuristic 기반 추천 문구)
- **하단: 수면 부채 게이지** (목표 대비 현재 상태 시각화)

### B. TrendsFragment (통계 화면)
- **상단: 기간 선택 탭** (7일 / 30일 / 전체)
- **중앙: 수면 시간 및 규칙성 혼합 차트** (Bar: 시간, Line: 규칙성)
- **하단: 수면 단계 분포 차트** (Stacked Bar or Donut Chart)

### C. SettingsFragment (설정 화면)
- **목표 수면 시간 설정:** (기본값 8시간)
- **알림 설정:** 추천 취침 윈도우 진입 시 알림 발송 여부.

## 4. Microcopy (한국어 문구 템플릿)

### 인사이트 카드 제목
- "최근 수면 패턴이 매우 규칙적이에요! 🎉"
- "수면 부채가 쌓이고 있어요. 😴"
- "이번 주 기상 시각이 조금 늦어지고 있네요."

### 추천 문구 (설명 가능성 포함)
- **시간 추천:** "지난 한 달간 가장 활동적이었던 날, 평균 7시간 30분을 주무셨어요. 오늘도 이만큼 주무시는 걸 추천해요."
- **윈도우 추천:** "일관된 생체 리듬을 위해 오후 11:15 ~ 11:45 사이에 취침하는 것이 가장 좋습니다."

### 데이터 부족 시
- "분석을 위한 데이터가 부족합니다. (최소 3일의 수면 기록이 필요해요)"

## 5. Edge Cases (예외 상황 처리)

- **자정 이후 취침 (Night Shift):** `sleep_start`가 00:00~06:00 사이인 경우, 전날 밤의 수면으로 간주하여 `health_daily`의 동일 row에 매핑 (Date 기준 보정 logic).
- **데이터 0~1일:** 분석 기능을 비활성화하고 "Health Connect 연동을 확인해주세요" 가이드 노출.
- **수면 단계(Stages) 없음:** 단계 비율 차트를 숨기고, '총 수면 시간' 중심의 간소화된 분석으로 자동 전환.
- **시차 발생 (Timezone):** UTC 기준이 아닌 기기의 Local Time 기준으로 일간 데이터를 재그룹화.

- [ ] 취침/기상 시각 표준편차를 통해 규칙성 점수가 산출되는가?

- [ ] Material3 디자인 가이드를 준수하여 카드가 배치되었는가?

- [ ] 다크 모드/라이트 모드에서 그래프 시인성이 확보되었는가?
